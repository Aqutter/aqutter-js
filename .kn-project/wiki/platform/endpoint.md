# 連線資訊

## Summary
網頁端靠殼在頁面載入時注入的全域物件 `window.aqutterEndpoint`（`{ port, token }`，已凍結）得知本機傳輸的埠與令牌，並以它是否存在判斷自己是否運行於殼內。兩個值在殼每次重啟傳輸伺服器後都會換新，所以網頁每次連線前都重新讀取、不快取。純瀏覽器與伺服端渲染沒有這個全域，client 因此不嘗試連線。

## 運作方式

![連線資訊的取得與更新](endpoint.取得與更新.svg)

1. 殼先啟動本機傳輸伺服器，伺服器每次啟動都產生新的隨機埠與令牌。
2. 殼在頁面載入時把兩個值放進全域物件，早於頁面自己的腳本執行。
3. 網頁建立連線前讀取全域，用裡面的埠與令牌組出連線網址。
4. 伺服器重啟時舊連線被關閉，殼同時重新定義全域並更新之後導覽用的注入腳本。
5. 網頁偵測到連線中斷，重連前再讀一次全域，拿到的就是新的埠與令牌。

## 規則

| 規則 | 說明 |
|---|---|
| 全域形狀 | 含埠（整數）與令牌（字串），物件已凍結，直接賦值改不了 |
| 讀取時機 | 每次連線前重新讀取，不快取 |
| 是否在殼內 | 全域存在才算；純瀏覽器與伺服端渲染一律視為不在殼內 |
| 內容不合法 | 埠或令牌型別不對時讀取失敗，傳輸排程重試 |
| 殼尚未注入 | 讀取失敗並重試，不丟給呼叫端 |
| 令牌的用途 | 擋掉同一台機器上其他程式連線；頁面內任何腳本都讀得到它 |
