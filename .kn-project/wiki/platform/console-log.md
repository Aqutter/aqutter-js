# 主控台日誌

## Summary
`installConsoleLog` 攔截網頁的 `console.*`，依設定把輸出送到 devtools、寫成檔案，或兩者並行；release 版可關閉 devtools 輸出以免多餘負擔。另提供 `console.to.*`，由呼叫端指定檔案的 provider、子目錄與檔名，目標也可以是每筆求值的函式。它同時捕捉未捕捉的網頁錯誤，並在安裝時向殼取回尚未寫檔的 Dart 錯誤紀錄。檔案實際由殼落地，本頁只講網頁端。

### 取回殼的錯誤紀錄

這張圖回答：殼端的 Dart 錯誤，怎麼寫進網頁設定的同一個檔案？

![取回並寫入殼的錯誤紀錄](console-log.取回錯誤紀錄.svg)

1. 安裝時網頁向殼取回所有尚未確認的錯誤紀錄，殼同時開始推送新紀錄。
2. 每筆紀錄以錯誤目標求值後寫成單行，目標沒設就沿用一般目標。
3. 只有寫成功的紀錄才回報確認，殼才刪除；失敗的留在殼端，下次載入再取。
4. 同一筆紀錄在寫入進行中不會重複寫；回滿 50 筆時會再取一次。
5. 寫檔關閉或不在殼內時不取回，紀錄全數留在殼端。

## 規則

| 規則 | 說明 |
|---|---|
| 設定的責任 | 本套件不判斷開發或發佈，是否輸出到 devtools 由 App 傳入 |
| 目標的形式 | 物件，或回傳物件的同步函式；函式回傳空值代表走殼的預設位置 |
| 函式丟例外 | 該筆改走預設位置，只提示一次 |
| 檔名的日期 | 省略檔名時由殼在每次寫入當下決定；用函式自行組檔名時由函式決定 |
| 未捕捉錯誤 | 預設捕捉，輸出為一般錯誤並轉給殼的錯誤回報接口，不重複寫入 |
| 錯誤紀錄行 | 單行，含來源、id、時間與訊息，有堆疊時接在後面 |
| 單筆上限 | 超過 64 KiB 截斷 |
| 非殼內與伺服端渲染 | 不寫檔；伺服端渲染下不安裝 |
